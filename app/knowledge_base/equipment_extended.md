# Мобильная связь и телефоны
- Лимит мобильной связи: 1000 рублей в месяц
- Превышение лимита: оплачивает сотрудник
- Корпоративный телефон: заявка в IT-отдел
- Тариф: безлимитные звонки внутри компании
- Личное использование: в разумных пределах
- Потеря телефона: немедленно сообщить в IT и заблокировать SIM

# Мониторы и периферия
- Второй монитор: заявка в ServiceDesk, категория Оборудование
- Размер монитора: 24 дюйма, по заявке можно 27
- 4K монитор: для дизайнеров и разработчиков
- Docking station: для MacBook по заявке в IT
- Наушники для удалёнки: по заявке в ServiceDesk
- Гарнитуры для конференций: Jabra или Polycom

# Обмен и выкуп техники
- Обмен на более мощный: с обоснованием через руководителя
- Выкуп после увольнения: по остаточной стоимости (амортизация 3 года)
- Возврат при увольнении: сдать всё в IT в последний день
- Комплект: ноутбук, зарядка, пропуск, телефон

# Страхование и инциденты
- Страхование техники: компания страхует всю технику
- Кража ноутбука: заявление в полицию + уведомить IT и СБ
- Оплата украденной техники: компания, если был заявлен инцидент
- Сломанный ноутбук дома: заявка в ServiceDesk, диагностика 1 день

# Специальное оборудование
- Планшет: для полевых сотрудников (iPad Pro или Samsung Galaxy Tab)
- Второй ноутбук: с обоснованием для разных проектов
- Тестовые устройства: через лабораторию оборудования
- Бронирование тестового устройства: через внутренний портал, до 2 недель

# Лицензии и софт
- Корпоративное хранилище: 100 GB автоматически, расширение до 500 GB
- Резервное копирование: автоматическое nightly backup
- Восстановление файлов: через IT из бэкапа, до 30 дней
- Dropbox: запрещён, только корпоративное облако
- Google Workspace: автоматически через корпоративную почту
- Slack: для всех сотрудников
- Jira: через руководителя + заявка в IT
- Confluence: автоматически при найме
- Figma: для дизайнеров и продактов
- Adobe: заявка через руководителя + обоснование
- ChatGPT: для продактов и аналитиков
- Copilot: заявка в IT + обоснование
- Midjourney: для дизайнеров
