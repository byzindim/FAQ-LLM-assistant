# Корпоративные инструменты и доступы
- GitHub: заявка через руководителя в IT
- Code review: минимум 2 аппрува от коллег
- CI/CD: GitLab CI с автотестами
- Деплой в продакшн: через merge request + approval

# Инциденты и безопасность
- On-call инженер: по графику, отвечает за инциденты
- Сообщить об инциденте: канал #incidents в Slack
- Runbook: в Confluence для частых инцидентов
- Продакшн-серверы: доступ только через bastion host + 2FA
- Пароли в коде: запрещены, использовать HashiCorp Vault

# Инфраструктура и облака
- Лимит облачных ресурсов: по бюджету проекта
- Оплата облачных сервисов: компания в рамках бюджета
- Личные облачные аккаунты: запрещены, только корпоративные
- Базы данных: доступ по заявке + обучение по безопасности
- Тестовые окружения: dev/staging/prod

# Безопасность данных
- Обучение по безопасности: обязательное раз в год
- Утечка данных: немедленно сообщить в security@company.ru
- Фишинг: 2FA + не открывать подозрительные ссылки
- USB-флешки: только корпоративные, зашифрованные (BitLocker/VeraCrypt)
- Clean desk policy: убирать документы со стола
- Фотографирование: только общие зоны, без экранов

# Удалённая работа и компенсации
- Work from anywhere: до 2 недель в месяц из любой страны
- Согласование работы из другой страны: за 2 недели через HR
- Компенсация интернета: 500 рублей в месяц по чеку
- Компенсация электричества: не предоставляется

# Оборудование для дома
- Эргономичное кресло: по мед. показаниям или заявке
- Мониторы для дома: один монитор по заявке
- Веб-камера: для удалённой работы по заявке
