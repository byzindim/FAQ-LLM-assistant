# Отпуска
- Основной отпуск — 28 календарных дней в году
- Отпуск можно делить на части, но хотя бы одна часть — не менее 14 дней
- Заявление подаётся за 2 недели через HR-портал

# Больничные
- Больничный лист оформляется электронно
- Первые 3 дня оплачивает работодатель, далее — ФСС
- Сообщить руководителю нужно в первый день болезни

# Премии
- Выплачиваются ежеквартально по результатам KPI
- Срок выплаты — до 10 числа месяца, следующего за кварталом

# Удалённая работа
- Разрешена до 3 дней в неделю по согласованию с руководителем
- Полная удалёнка — только по согласованию с HR и руководителем
